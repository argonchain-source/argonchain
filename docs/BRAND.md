# Brand: Argonmine

**Decision (2026-10-25): the chain is Argonmine, the coin is ARG, the domain is
argonmine.com.** The name is applied across the code base: brand constants
(`ui/ui.go`), address prefixes (`arg1…` mainnet, `targ1…` testnet, `rarg1…`
regtest), hash domain tags and proof-of-work salt (`Argonmine/…`), network
magic (`ARGM`, `TARG`, `RARG`), module path, binary names (`argonmined`,
`argonmine-app`, `argonmine-wallet`, `argonmine-explorer`, `argonmine-web`, `argonmine-bridge`), data directory
(`%LOCALAPPDATA%\Argonmine`, `~/.argonmine`), environment variables
(`ARGONMINE_*`), the genesis message, and all documentation. Genesis blocks
were re-mined after the change.

## Brand kit

The logo, app icon, colours, social images and usage rules are in `brand/`,
with the guidelines in `brand/README.md`; `brand/argonmine-brand-kit.zip`
holds all of it in one archive. The guidelines cover the mark's construction, clear space
(x = half the width of the mark), minimum sizes, approved colour
combinations with contrast ratios, typography, the ARG, uARG and wARG token
logos, and the wording rules (say "testnet" wherever test coins appear;
never call uARG an investment).

## Why this name

It says what the chain is (Argon2id mining), reads as two real words, and no
crypto project or company uses it. The only neighbour is "Argon (ARGON)", a
small freelancer-platform token on BNB Chain; the names and categories are
distinct enough.

## Ticker

**ARG** is used in the software. Before listing anywhere, check the ticker
against the exchange's namespace and fall back to **ARGN** if ARG is taken
there.
